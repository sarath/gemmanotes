## 2026-07-08 - ActiveWindow Import Rejection
**Learning:** The code review rejected the use of `activeWindow` without an import from `obsidian`, assuming it would cause a TypeScript compilation error. However, in Obsidian's typings (`obsidian.d.ts`), `activeWindow` and `activeDocument` are declared in the global scope (`declare global { ... }`) and are not exported. Attempting to import them (`import { activeWindow } from "obsidian";`) actually breaks the build with `error TS2305: Module '"obsidian"' has no exported member 'activeWindow'`. The build (`npm run build`) successfully resolves these as globals. Additionally, the base code was already using `activeDocument` correctly.
**Action:** When using Obsidian's global `activeWindow` or `activeDocument`, do not attempt to import them. If a reviewer flags this, rely on the successful `npm run build` (which includes `tsc --noEmit`) as verification that the global declaration is sufficient and correct.

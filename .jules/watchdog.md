## 2024-05-24 - Obsidian Popout Window Compatibility\n**Learning:** Using `window` directly for DOM operations (e.g., `window.getSelection()`, `window.innerWidth`) breaks compatibility with Obsidian's multi-window (popout) feature. However, `window` MUST still be used for timer functions (`window.setTimeout`, `window.setInterval`) to pass ESLint rules.\n**Action:** Always use `activeWindow` and `activeDocument` for DOM manipulations in Obsidian plugins, but retain `window` for timer operations.
